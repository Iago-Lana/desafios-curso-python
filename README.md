## 💻 Sobre o Projeto
Este repositório contém as soluções para os exercícios propostos no *Curso de Python 3* do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo Professor. Gustavo Guanabara.

O objetivo é praticar a lógica de programação e consolidar os fundamentos da linguagem Python.

## 🚀 Tecnologias e Conceitos Praticados
Durante a resolução dos desafios, foram aplicados os seguintes conceitos:

- [x] *Tipos Primitivos e Saída de Dados*
- [x] *Operadores Aritméticos*
- [x] *Módulos e Bibliotecas* (math, random, datetime, etc.)
- [x] *Manipulação de Strings*
- [x] *Estruturas Condicionais* (if, elif, else)
- [X] *Estruturas de Repetição* (for, while)
- [X] *Listas, Tuplas e Dicionários*
- [X] *Funções*
- [X] *Tratamento de Erros e Excessões*

## 📂 Como executar
Para rodar os códigos na sua máquina:

1. Tenha o *Python 3* instalado.
2. Clone o repositório:
git clone https://github.com/Iago-Lana/desafios-curso-python.git

3. Entre na pasta e execute o arquivo desejado:
  desafio001_saudacao.py
